# UI Design System

**Read `docs/ui-design.md` before writing any UI code for this website.**

It covers: color tokens, typography, card patterns, button classes, icon rules, section structure, animation conventions, and — critically — the mobile/tablet responsiveness requirements and checklist every page must pass before shipping.

All new pages must be tested at 375px (iPhone SE), 768px (iPad), and 1280px widths.
